# Waste Sort AI — Unified Premium Prototype

Open `code/index.html` directly in a modern browser.

Demo login: `operator / sort123`

## Product direction
The login's clean, editorial reference language is carried through the console: warm off-white canvas, restrained sage/charcoal palette, quiet borders, generous spacing, compact controls, and a dark physical-machine viewport so the hardware prototype remains legible.

## Core views
- Command Center
- Live Sorter
- System & Architecture
- Engineering Atlas

## Interaction model
The sorting cycle runs through:
DETECT → CAPTURE → INFER → FUSE → GATE → ROUTE → COMPLETE

The UI updates the active regions in place so scans do not refresh or rebuild the whole page.

## Local-safe
No CDN, npm, external API, or backend dependency.
